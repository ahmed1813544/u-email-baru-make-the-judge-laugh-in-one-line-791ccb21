## The line

> I told the barista I needed something strong, and she slid me her resignation letter.

## How it works

`main.py` (Python 3, stdlib only) writes that one original line to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). Running it
twice produces byte-identical output.

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
